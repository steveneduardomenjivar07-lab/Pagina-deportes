JSON: DATOS EN JUEGO

JSON significa JavaScript Object Notation. Es un formato de texto sencillo que permite representar e intercambiar información entre aplicaciones.

¿Qué es JSON?

JSON organiza información mediante pares de clave y valor, objetos y arreglos. Aunque su nombre incluye JavaScript, es un formato independiente que puede utilizarse con distintos lenguajes de programación.

¿Para qué sirve?

  • Intercambiar datos entre un servidor y una página web.
  • Guardar información estructurada en archivos de texto.
  • Representar equipos, jugadores, resultados o noticias.
  • Facilitar el procesamiento de datos en aplicaciones.

Ejemplo de datos futbolísticos

{
  "equipo": "FUTBOLMANÍA FC",
  "deporte": "Fútbol",
  "fundado": 2026,
  "activo": true,
  "jugadores": [
    "Carlos",
    "Daniel",
    "Miguel"
  ]
}

En este ejemplo, las claves describen los datos. Los valores pueden ser textos, números, valores booleanos, objetos, arreglos o null.

JSON y JavaScript

JavaScript puede convertir un texto JSON en un objeto mediante JSON.parse() y convertir un objeto en texto JSON mediante JSON.stringify().

const texto = '{"equipo":"FUTBOLMANÍA FC"}';
const datos = JSON.parse(texto);

console.log(datos.equipo);
CONCEPTOS CLAVE

Estructura de JSON

{ }
Objeto

[ ]
Arreglo
Contiene una lista ordenada.
"
Claves
Se escriben entre comillas dobles.
JSON no permite comentarios y requiere comillas dobles para las claves y los textos.
