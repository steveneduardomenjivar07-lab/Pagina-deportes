JSON DATOS EN ACCIÓN

JSON permite almacenar y enviar información de una manera sencilla y organizada.

JSON

¿Qué significa JSON?

JSON significa JavaScript Object Notation. Es un formato utilizado para intercambiar datos entre aplicaciones y servidores.

🔑

CLAVE

Identifica el dato que queremos guardar.

📄

VALOR

Es la información asociada a una clave.

📚

ARREGLOS

Permiten almacenar varios valores.

EJEMPLO

Datos de un jugador


{
    "nombre": "Messi",
    "edad": 39,
    "equipo": "Inter Miami",
    "posicion": "Delantero"
}
