JAVASCRIPT: EL MOTOR DE LA ACCIÓN

JavaScript es un lenguaje de programación que permite agregar comportamiento e interactividad a una página web. En FUTBOLMANÍA puede controlar botones, cambiar el tema, alternar idiomas y validar respuestas.

¿Qué es JavaScript Vanilla?

Se refiere al uso de JavaScript puro, sin depender de bibliotecas o frameworks externos. Trabaja junto con HTML y CSS para que la página responda a las acciones del usuario.

¿Cómo se utiliza?

Puede escuchar eventos como clics, modificar el contenido del DOM, validar formularios, almacenar preferencias en el navegador y actualizar partes de una página.

Ejemplo aplicado al fútbol

En una página deportiva, JavaScript puede mostrar una tarjeta de un equipo al pulsar un botón, filtrar noticias o calcular la puntuación de un cuestionario.

Ejemplo práctico

const boton = document.querySelector('#miBoton');

boton.addEventListener('click', () => {
  alert('¡Vamos, equipo!');
});
El código de ejemplo requiere un elemento HTML con id="miBoton" para funcionar.
GUÍA RÁPIDA

¿Qué debes recordar?

  • Permite crear interacciones sin recargar toda la página.
  • Manipula el DOM para cambiar contenido y estilos.
  • Puede guardar preferencias usando localStorage.
