jQuery: MENOS CÓDIGO, MÁS ACCIÓN

jQuery es una biblioteca de JavaScript que facilita la selección y manipulación de elementos HTML, la gestión de eventos, los efectos visuales y algunas solicitudes de datos.

¿Qué es jQuery?

jQuery permite realizar tareas comunes de JavaScript mediante una sintaxis más breve. Fue especialmente popular para simplificar la compatibilidad entre navegadores y crear efectos en sitios web.

¿Para qué sirve?

  • Seleccionar elementos HTML.
  • Responder a eventos, como los clics.
  • Mostrar y ocultar contenido.
  • Agregar o quitar clases CSS.
  • Realizar solicitudes de datos cuando el proyecto lo necesita.

Ejemplo aplicado a FUTBOLMANÍA

El siguiente ejemplo permite mostrar u ocultar una noticia deportiva al presionar un botón.

$('#botonNoticia').on('click', function () {
  $('#noticia').slideToggle();
});
Este ejemplo utiliza jQuery. Debes cargar la biblioteca y crear en HTML los elementos con los identificadores indicados.

Ventajas de jQuery

  • Sintaxis sencilla para tareas comunes.
  • Permite trabajar con eventos y efectos.
  • Facilita la manipulación del DOM.

¿jQuery o JavaScript?

JavaScript es el lenguaje de programación. jQuery es una biblioteca construida sobre JavaScript. Para muchos proyectos modernos, JavaScript puro también puede realizar estas tareas sin instalar una biblioteca adicional.
