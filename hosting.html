HOSTING Y DOMINIOS

Descubre cómo un sitio web puede pasar de estar en tu computadora a estar disponible en Internet.

WEB HOSTING

¿Qué es Hosting?

El Web Hosting es un servicio que permite almacenar los archivos de un sitio web para que las personas puedan acceder a él por Internet.

🖥️

COMPARTIDO

Varios sitios utilizan recursos de un mismo servidor.

⚙️

VPS

Ofrece recursos propios dentro de un servidor.

☁️

NUBE

Utiliza varios servidores conectados.

VERCEL

Publicar un sitio web

Vercel es una plataforma que permite desplegar proyectos web y conectarlos con repositorios de GitHub.

📁 1. Proyecto

Creamos los archivos de nuestro sitio web.

🐙 2. GitHub

Subimos nuestro proyecto a un repositorio.

🚀 3. Vercel

Conectamos GitHub y publicamos el sitio.

DOMINIOS

¿Qué es un dominio?

Es el nombre que las personas utilizan para entrar a un sitio web.

.COM

Uso comercial.

.ORG

Organizaciones.

.NET

Redes.

DNS

¿Cómo funciona el DNS?

🌐

DOMINIO

El usuario escribe el nombre del sitio.

🔎

DNS

Busca la dirección del servidor.

🖥️

SERVIDOR

Entrega los archivos de la página.

⚽

SITIO WEB

La página aparece en el navegador.
