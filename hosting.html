04 / PUBLICACIÓN WEB

DEL CAMPO A INTERNET

Conoce el alojamiento web, los dominios y los pasos necesarios para que FUTBOLMANÍA pueda estar disponible en internet.

INVESTIGACIÓN

¿CÓMO LLEGA TU WEB AL MUNDO?

Una página web necesita archivos, un lugar donde alojarlos y una dirección para que las personas puedan visitarla fácilmente.

01 / ALOJAMIENTO

Web Hosting

Es un servicio que almacena los archivos de una página web y los entrega a los visitantes a través de internet.

  • Guarda archivos HTML, CSS, JavaScript e imágenes.
  • Permite acceder al sitio desde otros dispositivos.
  • Puede ofrecer certificados SSL, estadísticas y otras herramientas.
02 / DIRECCIÓN

Nombre de dominio

Es la dirección fácil de recordar que las personas escriben en el navegador para encontrar una página web.

  • Ejemplo: futbolmania.com
  • Debe registrarse si está disponible.
  • Se conecta al servicio de alojamiento mediante la configuración DNS.
03 / PUBLICACIÓN

Despliegue web

Consiste en publicar los archivos del proyecto en una plataforma de alojamiento para que el público pueda visitar el sitio.

  • Subir o conectar el proyecto.
  • Configurar la carpeta y los archivos necesarios.
  • Probar los enlaces, imágenes y funciones.

¿Qué es Vercel?

Vercel es una plataforma de despliegue web que permite publicar proyectos y obtener una dirección web para compartirlos. Puede conectarse con repositorios de código para facilitar las actualizaciones.

Pasos para publicar FUTBOLMANÍA

  1. Organiza los archivos HTML, CSS y JavaScript en una carpeta.
  2. Prueba todas las páginas desde tu navegador.
  3. Sube el proyecto a un repositorio Git o utiliza un método de despliegue compatible.
  4. Importa el proyecto en Vercel y configura el despliegue.
  5. Abre la dirección publicada y comprueba que todo funcione.

¿Qué dominio elegir?

El nombre debe ser breve, fácil de escribir y relacionado con el proyecto. Antes de comprarlo, comprueba si está disponible y revisa su precio de renovación.

Un dominio personalizado no siempre es necesario: algunas plataformas de alojamiento ofrecen una dirección gratuita para comenzar.
CHECKLIST

Antes de publicar

  • Todos los archivos están guardados.
  • Los enlaces de navegación funcionan.
  • Las imágenes se muestran correctamente.
  • El sitio se adapta al móvil.
  • El formulario y el cuestionario se prueban.
